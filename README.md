## Hi, I'm Ehsan 👋

**Hand-coded in 2016. Built with agents in 2026.** Native Apple apps and small web tools for tennis, sleep, chess and 11+ exam prep.

**→ [See the project showcase](https://emrahman.github.io/EMRahman/)**

### Featured

1. **[DeuceMate](https://github.com/EMRahman/DeuceMate)**: score on your wrist, log how each point ended to feed an AI coach in ChatGPT, Claude or Gemini, and see how your game is trending. [On the App Store](https://apps.apple.com/app/id6757105622).
2. **[Somnus](https://github.com/EMRahman/Somnus)**: sleep debt, made visible. A native iOS app built on Apple Watch sleep data.
3. **[DeuceLeague](https://github.com/EMRahman/DeuceLeague)**: open-source club tennis league software (Postgres, Hono, TypeScript).
4. **[Farboard](https://github.com/EMRahman/Farboard)**: end-to-end encrypted chess with a friend, near or far. Companion: [ChessTracker](https://github.com/EMRahman/ChessTracker).
5. **[11+ Vocab Vault](https://github.com/EMRahman/11PlusVocabVault)**: vocabulary practice for 8–11 year olds. Companion: [11+ Maths Vault](https://github.com/EMRahman/11PlusMathsVault).
6. **[The Small Agent Stack](https://github.com/EMRahman/SmallAgentStack)**: a modular alternative to an all-in-one agent setup.

### Where it started

**[PiOrder](https://github.com/EMRahman/PiOrder)** (2016, hand-coded): a Raspberry Pi till, kitchen printer and online ordering system that ran my father's restaurant. It printed 12,738 orders and was featured in *The MagPi*, issue 57.
