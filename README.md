## Hi, I'm Ehsan 👋

**Hand-coded in 2016. Built with agents in 2026.** Native Apple apps, browser games and small web tools for tennis, sleep, chess and 11+ exam prep.

**→ [See the project showcase](https://emrahman.github.io/EMRahman/)**

### Featured

1. **[DeuceMate](https://github.com/EMRahman/DeuceMate)**: score on your wrist, log how each point ended to feed an AI coach in ChatGPT, Claude or Gemini, and see how your game is trending. [On the App Store](https://apps.apple.com/app/id6757105622).
2. **[Somnus](https://github.com/EMRahman/Somnus)**: sleep debt, made visible. A native iOS app built on Apple Watch sleep data. [On the App Store](https://apps.apple.com/app/id6812648966).
3. **[Farboard](https://github.com/EMRahman/Farboard)**: end-to-end encrypted chess with a friend, near or far. Companion: [ChessTracker](https://github.com/EMRahman/ChessTracker).
4. **[Side Quest](https://github.com/EMRahman/Games)**: a pocket arcade of twelve dependency-free browser games. [Play it](https://emrahman.github.io/Games/). Companion: [Team Side Quests](https://github.com/EMRahman/GameRooms) to play friends online with no accounts.
5. **[11+ Vocab Vault](https://github.com/EMRahman/11PlusVocabVault)**: vocabulary practice for 8–11 year olds. Companion: [11+ Maths Vault](https://github.com/EMRahman/11PlusMathsVault).
6. **[The Small Agent Stack](https://github.com/EMRahman/SmallAgentStack)**: a modular alternative to an all-in-one agent setup.

### Beta testing 🧪

**[DeuceLeague](https://github.com/EMRahman/DeuceLeague)**: open-source club tennis league software. It has migrated to Cloudflare (one Worker and one D1 database per club, in place of a Docker and Postgres VPS), completed six simulations of a 150-member club, and reached beta testing.

### Herdr desktop mods

The [Herdr desktop app](https://herdr.dev/) gives coding agents such as Claude Code, Codex, Antigravity (agy) and Pi a shared workspace. I check in on the same sessions with [Herdr on iPhone](https://herdr.dev/mobile/). I’ve retired the old Herdr TUI plugins.

- **[Herdr Prompts](https://github.com/EMRahman/herdr-prompts)** keeps recurring prompts in the sidebar. Click one to paste it into the active pane for editing, or use Send to submit it immediately.
- **[Herdr Context Monitor](https://github.com/EMRahman/herdr-context-monitor)** shows how full the context window is for each supported agent session, beneath the Agents list or in a floating window.
- **[Herdr Usage Monitor](https://github.com/EMRahman/herdr-usage-monitor)** shows the remaining allowance for each supported AI subscription in the sidebar, with a detailed view of limits, reset times and credits.
